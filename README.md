# Finity

**A Jellyfin client that feels like the streaming apps you already love.** Native on Windows and Android, with a proper video player (libmpv) inside.

### Download

Get the latest installer or APK from the **[Releases](../../releases/latest)** page.

- **Windows 10 / 11 (64-bit):** `Finity-Setup-*.exe`
- **Android 8.0+:** `Finity-Android-*.apk`
- **Android TV:** coming soon

You need a Jellyfin server. Finity does not host or provide any media, and is not affiliated with the Jellyfin project.

### Support Finity

Finity is made by one person. If it helps your movie nights, open **Settings → Send Support** inside the app.

### About this repository

This repository only holds the downloads and one small file, `supporters.json`, that the apps read to know who has a supporter badge or has unlocked Pro. The app's source code is private.
