A Jellyfin client for Windows that feels like a streaming app

Vyneo is a native Windows app for your Jellyfin server, with a real video player (libmpv) inside a smooth, calm interface.

Download Vyneo (free)See everything Vyneo does

What you get on Windows

  • A player that plays almost everything. libmpv handles most video, audio and subtitle formats, including PGS and styled ASS subtitles. The server is asked first, so Direct Play is used whenever it can be.
  • Smart Fit removes black bars baked into a video, only when that really makes the picture bigger.
  • Seek-bar previews with chapters and thumbnails, Skip Intro, Up Next with auto-play, and Previous / Next episode.
  • Discover. Browse what is popular and request what your server does not have through Jellyseerr, signing in with your Jellyfin account.
  • Mini player and picture-in-picture so you can keep watching while you browse.
  • Low Performance Mode for older PCs, Discord status, Stats for Nerds.
  • An installer that updates in place. Run the new installer over the old one and it offers to update; Vyneo can also check for updates itself.

Requirements

  • Windows 10 or 11, 64-bit
  • A Jellyfin server (10.9 or newer is best; Skip Intro needs 10.10 or newer)
  • No administrator rights needed: Vyneo installs for your user only

Installing

Download Vyneo-Setup from the latest release and run it. Windows may say “Windows protected your PC” because the installer is not code-signed yet: choose More info → Run anyway. Then enter your Jellyfin server address and sign in.

Frequently asked questions

Is Vyneo free?

Yes. Watching, browsing and requesting are free. Only the optional Server admin tools are a supporter extra.

Does Vyneo work with Jellyfin 10.9?

Yes, 10.9 or newer is best. Skip Intro needs Jellyfin 10.10 or newer.

Why does Windows warn me when I install it?

The installer is not code-signed yet, which needs a paid certificate. Choose More info, then Run anyway.

Does Vyneo track me?

No. There are no accounts and no analytics. Your password only goes to your own Jellyfin server.

Vyneo is a third-party app and is not affiliated with the Jellyfin project. It does not host or provide any media; it plays what is on your own Jellyfin server.
